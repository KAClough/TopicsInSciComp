# TopicsInSciComp

Notebooks for course on Topics in Scientific Computing at QMUL, run from 2023/2024 to 2026/27.

For more information and class resources see the [QM Plus pages](https://qmplus.qmul.ac.uk/course/view.php?id=33727) and the [wiki](https://github.com/KAClough/TopicsInSciComp/wiki).
